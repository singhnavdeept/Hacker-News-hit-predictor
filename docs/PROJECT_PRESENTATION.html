Problem Statement // Industry Challenge

The Content Engagement Paradox & The MLOps Gap

Over 10,000 developer and tech articles are submitted to Hacker News weekly; less than 25% ever achieve frontpage visibility or community traction (≥ 50 upvotes).

❌ The Academic Machine Learning Anti-Pattern
  • The Isolated Notebook Trap: Models trained in messy Jupyter cells with manual, non-reproducible local state.
  • Statistical Data Leakage: Preprocessing and scaling applied globally before cross-validation train/test splits.
  • Missing Deployment Workflows: No REST API microservices, Dockerization, or automated rollback capabilities.
  • Ignored Security Auditing: Hardcoded credentials, wide-open security groups (0.0.0.0/0 on port 22), and unchecked CVEs.
  • Runaway Cloud Budgets: Heavyweight architectures requiring GPU clusters that quickly exceed free allowances.
✅ The Cloud-Native MLOps Solution
  • Unified ColumnTransformer Pipeline: Encapsulates TF-IDF, categorical encoding, and feature scaling without leakage.
  • Immutable Docker Containerization: Runs identically on developer laptops and cloud EC2 instances with zero environment drift.
  • 7-Stage Declarative Jenkins Pipeline: Automated linting, testing, packaging, DevSecOps gating, and smoke testing.
  • Security Shift-Left: Automated policy-as-code audits with Checkov and Aqua Trivy inside the CI/CD pipeline.
  • Strict Free-Tier Cost Governance: 100% compliant with AWS Free Tier quotas ($0.00/mo operating budget).

ML Pipeline // Mathematical Rigor

Feature Engineering & Leak-Free Modeling

Combining Natural Language Processing (NLP) text vectorization, URL domain taxonomy, and temporal signals into a unified ColumnTransformer pipeline.

Feature Architecture & Signals
Signal Type Engineering Method Impact
NLP Headline TfidfVectorizer(max_features=3000, ngram_range=(1,2)) Captures technical anchors (e.g. "Show HN:", "Rust", "Postgres")
Domain Archetype Categorized into github, blogs, tech_media, paper, self Code repos experience 3.8x higher frontpage probability
Temporal Windows UTC Hour (0-23) & Day of Week (0-6) via StandardScaler Peak viral velocity observed between 13:00 - 18:00 UTC
Text Metrics Character length and token counts Penalizes overly short or spammy commercial clickbait
Why L2-Regularized Logistic Regression?
  • Sub-Millisecond Inference: Scoring takes < 5ms, allowing thousands of requests on low-cost hardware.
  • Ultra-Lightweight Storage: Serialized model is under 1 MB (compared to 500 MB+ for deep learning models).
  • Naturally Calibrated Probabilities: Directly yields genuine posterior probabilities without requiring post-hoc Platt scaling.
  • Direct Interpretability: Weights can be audited directly to understand why specific headlines succeed or fail.
  • Zero Overfitting on Small Benchmark Splits: Unlike unconstrained tree ensembles that overfit on sparse text, L2 penalty ensures smooth generalization.

Field Engineering // Troubleshooting

Operational Challenges Encountered & Overcome

Documenting real-world production engineering decisions, edge-case debugging, and system hardening on Amazon EC2.

Issue 1: Docker Build Out-Of-Memory (OOM) Crash

Symptom: SSH connection dropped abruptly during image build with client_loop: send disconnect: Connection reset.

Root Cause: EC2 t3.micro provides 1 GB RAM. Concurrently compiling models, parsing text, and extracting Docker layers consumed >950 MB, causing the Linux kernel OOM Killer to terminate SSH.

Solution: Allocated a 2 GB SSD Swapfile (/swapfile) on the EBS volume, expanding available virtual memory to 3 GB and completely eliminating memory starvation.

Issue 2: Amazon Linux 2023 Buildx Dependency

Symptom: docker compose up -d --build failed with compose build requires buildx 0.17.0 or later.

Root Cause: Amazon Linux 2023 unbundles the buildx binary from core compose packages.

Solution: Decoupled image construction using native docker build, followed by zero-rebuild composition using docker compose up -d --no-build.

Issue 3: Inbound Port 8000 Security Perimeter

Symptom: Microservice was active locally inside EC2 (curl 200 OK) but unreachable from external web browsers.

Solution: Hardened the AWS Security Group to cleanly separate Public API access (Port 8000 allowed to 0.0.0.0/0) while restricting management ports (22 SSH and 8080 Jenkins) to authorized admin CIDRs.

Issue 4: Live Container Layer Invalidation

Symptom: Browser loaded legacy API response after updating source code files.

Solution: Identified that Docker Compose preserved the 8-hour-old container due to matching service names. Implemented atomic container replacement using docker rm -f followed by tagged release rollout.
